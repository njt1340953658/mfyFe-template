# 用户管理模块前端需求规格说明

## 背景与目标
- 基于 React 18 + Ant Design 5 实现后台管理系统的用户管理模块前端页面
- 提供用户列表查询、新增、编辑、删除、状态切换等完整的 CRUD 功能
- 与后端 RESTful API（前缀 `/api/v1/users`）对接，实现数据的增删改查
- 支持响应式布局、权限控制、表单校验、操作确认等企业级特性

## 作用域

### 功能内
- 用户列表展示（分页、排序、筛选）
- 用户搜索（支持用户名、昵称、邮箱、手机号模糊搜索）
- 新增用户（表单填写、字段校验）
- 编辑用户（信息修改、密码重置）
- 删除用户（软删除、操作确认）
- 用户状态切换（启用/禁用）
- 操作权限控制（按钮级权限）

### 功能外
- 用户详情弹窗（可在后续版本扩展）
- 批量操作（批量删除、批量导出）
- 用户角色管理（独立模块）
- 用户登录日志查询（独立模块）
- 三方账号绑定

- 路由路径: `/system/user`
- 菜单位置: 系统管理 -> 用户管理

## 功能详细说明

### 1. 用户列表查询

#### 表格列定义
| 列名 | 字段 | 说明 | 宽度 |
|------|------|------|------|
| 序号 | index | 自动计算（分页序号） | 80px |
| 用户名 | username | 唯一标识，支持点击查看详情（预留） | 120px |
| 昵称 | nickname | 显示名称 | 120px |
| 邮箱 | email | 显示完整邮箱 | 180px |
| 手机号 | phone | 脱敏显示（138****0000） | 120px |
| 状态 | status | 标签显示（绿色：启用/红色：禁用） | 80px |
| 创建时间 | createdAt | 格式：YYYY-MM-DD HH:mm:ss | 160px |
| 操作 | actions | 编辑、删除按钮 | 150px |

#### 筛选条件
- **关键词搜索**: 单个输入框，支持用户名、昵称、邮箱、手机号模糊搜索
- **状态筛选**: 下拉选择（全部/启用/禁用）
- **创建时间**: 日期范围选择器（起始时间 - 结束时间）

#### 排序功能
- 默认按创建时间倒序
- 支持点击表头切换排序（创建时间、用户名）

#### 分页功能
- 默认每页 20 条
- 支持切换每页条数（10/20/50/100）
- 显示总条数和页码

### 2. 新增用户

#### 触发方式
- 点击「新增用户」按钮

#### 表单样式
- 使用 Ant Design Modal 弹窗
- 弹窗标题：「新增用户」
- 表单布局：labelCol={6} wrapperCol={18}

#### 表单字段
| 字段 | 组件 | 规则 | 说明 |
|------|------|------|------|
| 用户名 | Input | 必填，4-32字符，字母数字下划线 | 唯一性后端校验 |
| 密码 | Input.Password | 必填，8-32字符 | 强度提示：弱/中/强 |
| 确认密码 | Input.Password | 必填，与密码一致 | 校验一致性 |
| 昵称 | Input | 选填，1-64字符 | |
| 邮箱 | Input | 选填，邮箱格式 | 唯一性后端校验 |
| 手机号 | Input | 选填，11位数字 | 唯一性后端校验 |
| 头像 | Upload | 选填，图片上传 | 支持 jpg/png，<2MB |
| 状态 | Radio | 默认启用 | 启用/禁用 |

#### 操作按钮
- **确定**: 表单校验通过后提交，显示 Loading
- **取消**: 关闭弹窗，提示「确认放弃填写的内容吗？」

#### 提交逻辑
```typescript
// POST /api/v1/users
{
  username: string,
  password: string,
  passwordConfirm: string,
  nickname?: string,
  email?: string,
  phone?: string,
  avatar?: string,
  status: 0 | 1
}

// 成功响应
{
  code: 0,
  message: "OK",
  data: { id: number }
}

// 失败响应（示例）
{
  code: 40001,
  message: "用户名已存在",
  data: {}
}
```

#### 成功/失败处理
- **成功**: 提示「新增用户成功」，关闭弹窗，刷新列表
- **失败**: 显示后端返回的错误信息，表单不关闭

### 3. 编辑用户

#### 触发方式
- 点击列表操作列的「编辑」按钮

#### 表单样式
- 使用 Ant Design Modal 弹窗
- 弹窗标题：「编辑用户」

#### 表单字段
| 字段 | 组件 | 规则 | 说明 |
|------|------|------|------|
| 用户名 | Input | 禁用，不可编辑 | 显示当前用户名 |
| 昵称 | Input | 选填，1-64字符 | |
| 邮箱 | Input | 选填，邮箱格式 | 唯一性后端校验 |
| 手机号 | Input | 选填，11位数字 | 唯一性后端校验 |
| 头像 | Upload | 选填，图片上传 | 支持 jpg/png，<2MB |
| 状态 | Radio | 必选 | 启用/禁用 |
| 重置密码 | Collapse | 选填 | 展开后显示「新密码」和「确认密码」 |

#### 提交逻辑
```typescript
// PUT /api/v1/users/{id}
{
  nickname?: string,
  email?: string,
  phone?: string,
  avatar?: string,
  status: 0 | 1,
  password?: string,        // 仅在重置密码时传递
  passwordConfirm?: string  // 仅在重置密码时传递
}
```

#### 成功/失败处理
- **成功**: 提示「编辑用户成功」，关闭弹窗，刷新列表
- **失败**: 显示后端返回的错误信息

### 4. 删除用户

#### 触发方式
- 点击列表操作列的「删除」按钮

#### 确认对话框
```
标题: 删除确认
内容: 确定要删除用户「{username}」吗？此操作不可恢复。
按钮: [取消] [确定]
```

#### 提交逻辑
```typescript
// DELETE /api/v1/users/{id}

// 成功响应
{
  code: 0,
  message: "OK",
  data: {}
}
```

#### 成功/失败处理
- **成功**: 提示「删除用户成功」，刷新列表
- **失败**: 提示错误信息「删除失败：{后端返回的错误信息}」

### 5. 状态切换

#### 实现方式
- 表格状态列使用 Switch 组件
- 点击 Switch 直接触发状态切换

#### 提交逻辑
```typescript
// PUT /api/v1/users/{id}
{
  status: 0 | 1  // 0: 启用, 1: 禁用
}
```

#### 成功/失败处理
- **成功**: 提示「状态修改成功」，更新当前行数据
- **失败**: Switch 回滚到原状态，提示错误信息

## 数据交互

### API 接口列表
| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取用户列表 | GET | /api/v1/users | 支持分页、筛选、排序 |
| 创建用户 | POST | /api/v1/users | 新增用户 |
| 更新用户 | PUT | /api/v1/users/{id} | 编辑用户信息 |
| 删除用户 | DELETE | /api/v1/users/{id} | 软删除用户 |

### 查询参数（GET /api/v1/users）
```typescript
{
  page?: number,          // 页码，默认 1
  pageSize?: number,      // 每页条数，默认 20，最大 100
  keyword?: string,       // 关键词搜索
  status?: 0 | 1,         // 状态筛选
  createdFrom?: string,   // 创建时间起（ISO 8601）
  createdTo?: string,     // 创建时间止（ISO 8601）
  sortBy?: 'created_at' | 'username', // 排序字段
  order?: 'asc' | 'desc'  // 排序方向
}
```

### 响应数据结构
```typescript
{
  code: 0,
  message: "OK",
  data: {
    list: Array<{
      id: number,
      username: string,
      nickname: string,
      email: string,
      phone: string,        // 前端脱敏处理
      avatar: string,
      status: 0 | 1,
      createdAt: string,
      updatedAt: string
    }>,
    total: number,
    page: number,
    pageSize: number
  }
}
```

## 校验规则

### 前端校验
- **用户名**: 4-32字符，只能包含字母、数字、下划线
- **密码**: 8-32字符，需包含字母和数字
- **确认密码**: 必须与密码一致
- **邮箱**: 符合邮箱格式（正则：`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`）
- **手机号**: 11位数字（正则：`/^1[3-9]\d{9}$/`）
- **昵称**: 1-64字符
- **头像**: 图片格式（jpg/png），大小 < 2MB

### 后端校验反馈
- **唯一性冲突**: code 40901，message 提示具体字段
- **参数错误**: code 40001，message 提示错误原因
- **未找到**: code 40401
- **服务器错误**: code 50000

## 权限控制

### 按钮级权限
| 操作 | 权限标识 | 无权限处理 |
|------|----------|------------|
| 新增用户 | system:user:add | 按钮隐藏 |
| 编辑用户 | system:user:edit | 按钮禁用/隐藏 |
| 删除用户 | system:user:delete | 按钮禁用/隐藏 |

### 权限获取
- 从 Redux Store 的 `auth.permissions` 中获取当前用户权限列表
- 使用自定义 Hook `usePermission(code: string)` 判断是否有权限

## 交互体验

### Loading 状态
- **列表加载**: 使用 Ant Design Table 的 loading 属性
- **操作提交**: 按钮显示 Loading 状态，禁用重复点击
- **状态切换**: Switch 组件显示 Loading

### 提示信息
- **成功提示**: 使用 `message.success()`，3秒自动消失
- **错误提示**: 使用 `message.error()`，5秒自动消失
- **警告提示**: 使用 `Modal.confirm()` 进行危险操作确认

### 响应式适配
- **PC 端**: 表格完整显示所有列
- **移动端**: 
  - 隐藏部分非关键列（邮箱、创建时间）
  - 操作按钮收起为「更多」下拉菜单
  - 搜索区域改为展开/收起

## 错误处理

### 网络错误
- 请求超时: 提示「请求超时，请稍后重试」
- 网络断开: 提示「网络连接失败，请检查网络」

### 业务错误
- 根据后端返回的 code 和 message 显示具体错误信息
- 表单字段错误: 在对应字段下方显示红色错误提示

### 异常边界
- 使用 React Error Boundary 捕获组件渲染错误
- 显示友好的错误提示页面

## 性能优化
- 表格数据使用虚拟滚动（数据量 > 1000 条）
- 图片懒加载和压缩
- 防抖搜索（输入停止 500ms 后触发）
- 使用 React.memo 优化不必要的重渲染

## 可访问性
- 表单字段使用语义化 label
- 支持键盘导航（Tab、Enter）
- 操作按钮提供 aria-label
