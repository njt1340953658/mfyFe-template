# 技能文档集合 (comSkills)

本目录包含 UniApp Vue3 微信小程序项目开发所需的各项技术技能文档。

---

## 📚 文档列表

### 核心技能

#### 1. [Vue 3 Composition API](./vue3-composition-api.md)
Vue 3 组合式 API 的使用指南，包括响应式 API、生命周期钩子、组件通信等。

**适用场景**:
- Vue 3 组件开发
- Composition API 使用
- 响应式数据管理

---

#### 2. [UniApp 开发指南](./uniapp-guide.md)
UniApp 跨端开发框架的使用指南，包括 API、组件、配置、生命周期等。

**适用场景**:
- 微信小程序开发
- 跨端应用开发
- UniApp 特性使用

---

#### 3. [Pinia 状态管理](./pinia.md)
Pinia 状态管理库的使用指南，包括 Store 定义、状态管理、持久化等。

**适用场景**:
- 全局状态管理
- 数据持久化
- 模块化状态管理

---

#### 4. [HTTP 请求封装](./request.md)
基于 uni.request 的 HTTP 请求封装，包括拦截器、错误处理、类型定义等。

**适用场景**:
- API 接口调用
- 请求拦截和错误处理
- Token 认证管理

---

#### 5. [TypeScript 类型系统](./typescript.md)
TypeScript 在 UniApp 项目中的应用，包括类型定义、泛型、工具类型等。

**适用场景**:
- 类型安全开发
- API 类型定义
- 组件类型声明

---

## 🎯 使用说明

### 如何使用这些文档

1. **新手入门**: 
   - 先阅读 [UniApp 开发指南](./uniapp-guide.md)
   - 然后学习 [Vue 3 Composition API](./vue3-composition-api.md)
   - 最后掌握 [Pinia 状态管理](./pinia.md)

2. **功能开发**:
   - 查阅相关技能文档的示例代码
   - 参考最佳实践
   - 复制代码模板进行修改

3. **问题排查**:
   - 搜索关键词定位问题
   - 查看常见问题章节
   - 参考错误处理方案
