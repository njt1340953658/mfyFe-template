- [代码审查规范](./code-review-guide.md) - 代码审查流程和要点

### 项目配置
- [环境变量配置](./env-config.md) - 环境变量说明和配置示例

- [开发流程](./development-workflow.md) - 从需求到上线的完整流程

## 使用说明

### 新成员入职
1. 阅读 [编码规范](./coding-standards.md)
2. 了解 [开发流程](./development-workflow.md)
3. 熟悉 [Git 提交规范](./git-commit-guide.md)
4. 掌握 [分支管理策略](./branch-strategy.md)

### 开始新需求
1. 参考 [开发流程](./development-workflow.md) 创建分支
2. 按照 [编码规范](./coding-standards.md) 编写代码
3. 提交时遵循 [Git 提交规范](./git-commit-guide.md)
4. 发起 PR 并参考 [代码审查规范](./code-review-guide.md)

### 项目部署
1. 检查 [环境变量配置](./env-config.md)
2. 参考 [构建配置说明](./build-config.md) 进行构建
3. 按照 [部署流程](./deployment.md) 进行部署

## 文档维护
- 配置文件由项目负责人维护
- 发现问题或有改进建议，请提交 Issue 或 PR
- 重大变更需经过团队讨论确认
